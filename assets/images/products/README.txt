This folder holds the product photography for the site.

Right now it contains one hand-built SVG illustration per category
(aerators.svg, floating-products.svg, etc.) used as safe, self-hosted
placeholder artwork — no external hotlinking, no third-party copyrighted
photos presented as Jay Kay Aqua Tech's own product images.

The easiest way to add real photos going forward is through the admin
panel: Admin → Products → Edit Product → Main Image / Additional Images.
Uploads land in this exact folder automatically. If you'd rather add
files directly, drop them here and update the relevant product's image
path in the database (via the admin) or the <img> reference in HTML.
